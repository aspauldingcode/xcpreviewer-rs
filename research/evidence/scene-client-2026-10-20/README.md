# Workspace action completion and native atomic signal

Following the FrontBoard workspace route reaches a client-proxy block at current-ASLR0x24ffd0aa8. Exact runtime selector references identify sceneID:sendActions:toExtension:completion:, performAfter:withBlock:, signal and hasBeenSignalled. The code sends the scene identifier/actions plus an optional extension class converted to a class-name string and supplies a completion block. It schedules a separate five-second fallback on a workspace queue (LLVM immediate5.0). The completion and fallback both invoke the same copied block. That block calls BSAtomicSignal.signal and performs its guarded workspace bookkeeping only for the winning caller. The fallback inspects hasBeenSignalled for logging, then invokes the common block regardless. These are source findings; neither workspace transmission nor the five-second timer path was executed.
