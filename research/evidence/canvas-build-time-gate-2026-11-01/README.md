# Native build timestamp and file-event suppression

This unit semantically qualifies previously byte-verified event-handler fragments. A build-start event constructs Foundation.Date() and stores a present optional lastBuildTimestamp. After assignment, a true low payload flag exits; false schedules the coalescer, clears/releases the cached builder, requests an optional workspaceChanged scene update and pauses with imported userInitiatedBuild reason. The payload flag's upstream meaning remains unknown.

The modified-file path checks the optional timestamp. Missing timestamp proceeds to the later external-file invalidation/filter gate. With a timestamp present, Date().timeIntervalSince(lastBuildTimestamp) is compared to native immediate 2.0. A value at or below two seconds enters suppressed cleanup/return; a value above two proceeds to the later gate. This is a source event-suppression check, not a measured debounce, monotonic-clock guarantee, scheduled retry or observed timing experiment.

source.py compares 772 instruction bytes across bounded handler fragments, pins the image UUID/SHA and validates seven selected call bindings. It binds the imported pause reason through the Mach-O indirect symbol table for its GOT slot, rather than guessing enum tags. Selected native stores/branches and floating constant/comparison are checked. Earlier source ranges were expanded before packaging to include the pause and shared cleanup fragments. REA reports the expected server identity aligned with no open binary session. The unchanged prior Ghidra listing limitation was not retried.
