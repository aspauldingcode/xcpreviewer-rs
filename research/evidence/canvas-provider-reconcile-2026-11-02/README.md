# Provider identity matching and preview-source refresh

Pinned PreviewsScenes source qualifies the provider half of collector reconciliation. It iterates incoming ProviderSource values, obtains source.id, and looks up each in the captured IdentifiedSet of existing providers. A miss constructs Provider(source:isPinned:). A hit reuses the provider value, sets its new source and pin flag, and transforms previews exposed after those setters. Setter internals remain unqualified; value reuse does not prove object/session identity preservation or unchanged preview contents.

The preview transform reads DiscoveredItem. A registry item returns after local cleanup. A preview item lacking providerInstance likewise skips the update path. A present provider instance receives the new providerSource, is wrapped into PreviewInstance.provider and DiscoveredItem.preview, then passed to Preview.update(withItem:). Actual enum case imports identify preview and registry; unknown cases reach the native diagnostic/trap. Preview.update internals and its downstream state/resource effects remain open.

Normal output appends one result per input source in input order; empty input returns empty output. Old entries absent from input are not appended by this mapper. This is exclusion from the reconstructed value array, not observed teardown, callback cancellation, renderer termination or transport/OS resource settlement. Constructor/setter effects, duplicate identity behavior, registry reconciliation and actual runtime reuse/removal remain unqualified.
