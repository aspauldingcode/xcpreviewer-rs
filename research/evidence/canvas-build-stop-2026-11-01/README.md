# Build-stop auto-refresh source gate

This source unit qualifies the consumer of the previously recovered listener build-stop event. It pins PreviewsXcode and PreviewsPipeline independently and compares all 5,160 inherited handler instruction bytes against fresh bounded LLVM output. Ten actual call bindings and native field metadata qualify the selected route; no new runtime event is delivered.

The tag-4 build-stop route reads lazy UserDefault<Bool> _shouldAutoResumeWhenBuildSucceeds. Its low bit AND the stop payload low bit must be true, otherwise the function returns. The payload was independently traced to IDEBuildOperation.result == 1 in canvas-build-listener-2026-11-01. That result enum name and the effective preference/default remain unobserved.

A missing workspaceScene returns. With a scene present, previewService.buildingState supplies the enum inspected by swift_getEnumCaseMultiPayload. Pinned native reflection names two payload cases (blocked, paused) followed by two empty cases (running, empty). The checked subtraction/unsigned comparison returns for running/empty. blocked/paused proceed after associated-value cleanup; this route does not compare a particular pause/block reason.

The surviving path schedules environmentCoalescer, clears/releases cached lastWorkspaceBuilder, constructs PreviewUpdateReason.userRequestedRefresh and requests scene.setNeedsUpdate if a scene remains present. This establishes request submission in source. It does not establish immediate unpause, build execution/completion, resumed rendering, persistent state or measured timing.

source.py verifies image UUID/full SHA, reflection counts/names/payload flags, concrete metadata pointer provenance and selected opcodes/imports. It interprets the pinned state comparison for all four valid logical tags. verify.py copies original readers into a fresh temporary directory and compares complete findings. This replay is static; no invented native enum object or private ABI invocation occurs. REA is aligned with no binary session open; the prior unresponsive Ghidra listing is not retried. Raw Apple code remains temporary/local. The package contains original readers, hashes and sanitized findings only.

Actual native positive-change and failure controls, effective preferences, result enum semantics, project/version/target coverage, complete session/state and refresh behavior remain required. No Rust/product change or Rust test rerun. Both milestones and all nine full recovery acceptance areas remain open.
