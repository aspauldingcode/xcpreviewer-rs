# Nested bitmap and selectable-region reconstruction

GhidraVibe MCP reused the current owned messaging program and imported PreviewsFoundationHost. REA independently bound and closed both exact current framework hashes. Direct native symbols, Ghidra decompilation and separate LLVM instruction inspection recovered the bitmap/region/geometry boundaries. Raw pseudocode, assembly and symbols remain local under research/raw/direct-bitmap-region-20261019 and are excluded from this package.

Bitmap decoding first attempts optional UInt32 bitmapInfo. When present, legacy byteOrder is not decoded; otherwise little/big select0x2002/0x4002. Missing bitsPerComponent/bitsPerPixel/colorSpace default to8/32/the public sRGB constant. Required data, width, height and bytesPerRow follow. SelectableRegion requires path and rect, with optional serializedAccessibilityElement data. Following the dependency into Foundation recovers CGRect as one flat dictionary of required CGFloat x,y,width,height fields. An initial temporary opaque-rect candidate was replaced before publication; it is not claimed as native wire structure.

The original Rust typed-tree decoder now combines these nested structures with the prior outer RenderPayload defaults. Seven new tests cover defaults, both byte orders, explicit bitmapInfo bypass of malformed legacy order, UInt32 range errors, required fields, complete data preservation, Unicode path/optional accessibility bytes, flat geometry and the complete outer tree. All16 crate unit tests and all target/doc-test builds pass offline after formatting. The8-byte bitmap test retains its complete data, including four synthetic row-padding bytes; this is an original test fixture, not native allocation evidence. No physical allocation or padding equality is claimed.

The decoder consumes explicit in-memory property-list values. It is not a binary/XML plist parser and does not yet reproduce Foundation numeric/null coercions or native error identities. Rust errors are original adapter errors; required/default/precedence structure is statically recovered. No dimensions/finiteness normalization was invented where native behavior was unmeasured. No live packet or renderer integration is accepted from these tests.

A changed runtime observation targeted the existing owned PreviewLab debug process instead of Xcode. Its full executable/start identity was checked and preserved. Frida17.23.1 used the corrected cancellable API and a5-second attach budget; OperationCancelledError arrived before a session existed, with no script loaded. No module list, hook, swizzle, private data or successful injection is claimed. Xcode and PreviewLab were not terminated, no app was re-signed and no system protection changed. This failure stays separate from successful static reconstruction; unchanged attach retries are not planned.

No Xcode built-in MCP or private bridge was used, and no owned UI workspace session was created. Existing user windows/workspaces were untouched. Both milestone acceptance contracts remain open.
