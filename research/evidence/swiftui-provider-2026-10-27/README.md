# Explicit SwiftUI PreviewProvider capture

The producer accepts an explicit qualified PreviewProvider type with --provider, mutually exclusive with --factory. The shipped SDK interface constrains Previews to View and isolates the public static getter to MainActor. The original wrapper enforces that protocol with a generic helper and renders the complete returned composition through public ImageRenderer.

Two owned native captures (provider and equivalent default factory) have identical decoded payloads and all 24,576 pixels match the expected asymmetric red/blue raster. Four negative selectors (nonconforming type, conflicting flags, expression injection syntax, empty type) fail at their expected stages and preserve the last good payload. The qualified existing native RenderPayload codec accepts the provider capture and returns its complete canonical value. Native PNG pixels, unchanged host converter and actual WASIp1 converter match every output byte. Native codec value/plist copies were destroyed once each. No Rust implementation changed; the previous 409-test result was not rerun or counted again. No new browser interaction was performed.

SDK facts carry source-path/hash/line provenance in sdk-contract.json; results are bounded public-renderer observations, not private Canvas provider discovery or lifecycle. No _PreviewProvider ABI invocation, provider enumeration, #Preview registry, grouped-variant extraction, device/layout metadata application, interactive state migration or resource settlement is claimed. Both milestones remain open.

verify.py checks current producer pins, copies the owned controls into a disposable directory and reruns the bounded native compilation/rendering, negative selection, private-codec, PNG and host/WASM comparisons. The private codec executable and converter artifacts are inherited pinned dependencies from the prior source-preview unit. This is not an independent fresh rebuild of those dependencies. They must still exist locally and match their recorded hashes. Original source input is compiled and executed intentionally. Raw Apple source/disassembly and binaries are not included here.

Publication remains under the existing explicit approval gate. No commit, push or GitHub update was attempted. Prior source-preview producer pins describe its historical revision; pins.json describes this new producer revision.
