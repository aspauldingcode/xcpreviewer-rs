# Native Canvas buildable producer

This source-only unit closes the previously untraced connection between the native scheme-selection policy and the workspace builder's cached scheme-buildable set. It does not establish runtime execution or Canvas parity.

Pinned PreviewsXcode ARM64 `XcodeWorkspaceSceneHost.makeBuilder()` directly imports `PreviewsIDEAPI.BuildSystem.buildables(scheme:workspace:runContextManager:executionEnvironment:)`. The call uses the scene's scheme, workspace, run-context manager and execution environment. The result is iterated into BuildableWrapper values containing a FoundationHost.Ref and the buildable's display name. The collection is uniqued to a set. The set result passes through scratch offset 0xa8 and is stored on the newly allocated XcodeWorkspaceBuilder using the symbol-identified allSchemeBuildables field-offset global. This is a static data-flow inference grounded in the selected instruction and import bindings, rather than a private-ABI invocation.

The prior canvas-project-binding unit recovers the imported selection policy. The prior canvas-workspace-caller unit recovers consumption of this cache by schemeBuildablesAndDirectDependencies and its dependency-closure request with implicit dependencies false. Together they establish the source chain. The prior native PreviewLab UI observation is contextual only and was not repeated here; no observed UI action is causally attributed to these functions.

`source.py` pins the complete image UUID/SHA, checks 3,512 disassembled instruction bytes against section-mapped Mach-O bytes, binds eight selected calls from the indirect-symbol/import and defined-symbol tables, and verifies selected result/field-store register flow. `verify.py` checks original reader pins and runs a fresh copied source reader; complete findings must agree. Raw disassembly is written only to a private temporary directory and is not part of this package. No Apple binaries or disassembly are included.

The preliminary ADRP/LDR reference scan found only a consumer and destructor for the field global. It was limited to a short pattern window and missed the producer's ADRP/ADD/LDR form; it never established producer absence. Import-stub callers supplied the successful route.
