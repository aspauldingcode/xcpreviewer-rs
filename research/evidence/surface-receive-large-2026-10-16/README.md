# Owned receive-size failure and recovery

This active one-task Mach/IOSurface experiment adds a receive-side failure boundary to R1. Each fixture executes two controls on separately created owned surfaces and private endpoints: a correctly sized receive, then a header-sized receive with MACH_RCV_LARGE followed by a full receive. It uses no external rendezvous, forked peer, UI, Xcode workspace, private capture bridge or user process. The inherited helper's unrelated peer paths are compiled but not invoked. Own source, public SDK headers and complete owned allocation goldens are retained; executables and Apple binaries/private dumps are excluded.

The predicted discriminator is that LARGE reports the required size while retaining the queued descriptor for recovery; unexpected consumption, counts or bytes reject that scoped expectation.
