## Executed primary control

After a two-second no-action baseline, the harness deletes the guarded original PreviewLab.swift and confirms its absence. A temporally correlated native workspace invocation reaches removed-files block 0x2499c4, enters/returns the known filter, then returns from the handler. The selected workspace removed-location, EditorScene removed-location, coalescer and scene-update entries do not occur in this invocation. The eight-second scene-propagation wait ends false. The filter's return contents and payload paths are not decoded. Thus this does not establish why propagation stops, prove that the array is empty, or bind the native payload conclusively to this filename. The event timing, quiet baseline and sole controlled file mutation are correlation evidence. Return from the filter/handler is not disposal or resource-release evidence.
