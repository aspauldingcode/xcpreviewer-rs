# Native Canvas modified-file selection policy

Recovered source behavior in ModifiedFilesUpdateFilter.filterModifiedFilesForUpdate and shouldUpdateModifiedFile. No file notification was delivered, no native refresh was triggered, and no product implementation changed.

The array filter first skips entries whose optional DVTFileDataType is absent. Typed entries are retained only when shouldUpdateModifiedFile returns true. The predicate excludes paths accepted by isOpenAndThunkable; the helper's internal membership rules remain unqualified in this unit. It also excludes types conforming to com.apple.application-bundle, com.apple.pluginkit, com.apple.framework or com.apple.dt.swiftpm-user-managed-folder. Remaining paths are excluded when any lowercased path component equals .swiftpm, or when pathExtension equals swiftpm. The inspected extension comparison does not lowercase its input. Other typed entries pass the predicate. The difference between a lowercased component check and the unlowercased extension check is retained, not normalized by the reader.

These rules govern this native modified-file selection function. They do not establish that excluded files never update through other routes, that all passing files cause full builds, or that SwiftUI state/refresh parity is complete. Prior handler source identifies a separate modified-file filter gate and followup work; its full result-to-session behavior remains open. Existing owned source watcher uses an original scheduling policy and is not relabeled as native Canvas parity.

The verifier pins the installed ARM64 image UUID/SHA, compares all 2,920 bounded instruction bytes against section-mapped image bytes, binds eleven selected calls through Mach-O metadata, validates branch/result anchors, decodes the .swiftpm/swiftpm constants from selected native immediate-building instructions, and checks all four native type-name strings. Initial exploration ended the filter at next makeBuilder and included an adjacent editor-settings key-path setter; final source verification ends at the actual next symbol 0x24e808 and excludes that unrelated setter. This was a range refinement, not a native execution failure. Exploratory isOpenAndThunkable disassembly stays local; its byte range is not counted or represented as qualified here.

verify.py checks reader hashes, copies original reader sources to a fresh temporary workspace, reruns bounded static verification and requires complete findings equality. Raw disassembly, symbol inventories and Apple binaries are excluded from this package. REA identity is aligned with no open binary session; the unchanged earlier Ghidra listing limitation is not retried. No private native ABI, synthetic notification, GUI action, build/refresh, process signal, preference change, Rust/product change or Rust test rerun occurred. Full runtime/all-target Canvas recovery and both milestones remain open. Publication and matching GitHub issue updates remain locally deferred behind the existing explicit approval gate.
