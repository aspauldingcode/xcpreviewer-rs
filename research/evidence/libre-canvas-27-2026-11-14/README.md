# OS/SDK27, independent appearance and native counter — 2026-11-14

These are scoped runtime/product checks, not full Xcode Canvas parity. All final native preview receipts use `arm64-apple-macos27.0` and SDK27.2. Older 26-target experiments are superseded, not relabeled.

`independent-themes.json` records actual Chromium controls and an owned persistent `NSHostingView` rendering adaptive SwiftUI text/background. Light background is `[255,255,255,255]` with dark glyphs; dark background is `[30,30,30,255]` with light glyphs. Independent UI-light/canvas-dark and UI-dark/canvas-light pass. Changing UI alone preserves the native artifact hash. Browser media changes exercise Canvas Auto, UI Auto and both Auto. Titlebar pixels change with the accepted canvas frame, not DOM theme. Browser preference changes are emulated; physical OS settings are not changed. Native content backing is640×416 for320×208 points; exported canvas including titlebar is640×480. No 1x image is enlarged to claim Retina.

`browser-counter.json` exercises actual Chromium click → local authenticated API → point mapping → native `NSEvent.leftMouseDown` then `leftMouseUp` → owned `NSWindow.sendEvent` → persistent SwiftUI `@State` → native bitmap → original WASI decoder → browser canvas. Plus changes the count glyph; minus restores its exact original pixel hash. View-only titlebar clicks forward no events. Out-of-bounds API input and transparent mask-corner input reject with400. The Retina toggle changes1200×800 to600×400 backing pixels while preserving600-point CSS width, then restores2x. Fit-scaled mobile clicks also change the actual count glyph. `counter-one-desktop@2x.png` visibly shows count1. This is public AppKit reconstruction with runtime evidence, not proof of Xcode's private event wire protocol, touch, drag, keyboard, IME or all widget behavior.

The same browser check selects the installed iPhone17Pro profile:402×874 layout points,804×1748 rendered pixels at2x, transparent mask corner, exact aspect ratio after Fit scaling. The mask is rendered locally from the installed catalog PDF and checked against its declared layout extent. Apple PDF/assets remain local and are not vendored. This is a **Mac SwiftUI geometry preview**, not native iOS semantics, safe-area/status-bar fidelity or exact hardware-bezel artwork.123 catalog display profiles are discovered on this host; only this selected mobile profile is exercised here. iPhone12mini's375×812 canvas is distinguished from its differently sized framebuffer by metadata and synthetic tests.
