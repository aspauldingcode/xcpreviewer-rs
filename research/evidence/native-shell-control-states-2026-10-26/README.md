# Native shell update control-state wire facet

This unit executes shipped `PreviewsMessagingHost.ShellUpdatePayload.init(propertyListValue:)`, its PropertyList encoder, metadata accessor and destruction witness inside an owned ARM64 helper. It does not attach to or operate user Xcode/simulator processes. Both milestones remain incomplete.

## Recovered contract and original implementation

`controlStates` is an optional ordered `[PlistValueBox]` field. A missing key decodes to nil and the encoder omits it; a present empty array remains present-empty. Every element must decode as a whole PropertyList dictionary. Empty dictionaries, arbitrary `value` types, unknown box members, ordering, duplicate multiplicity and original Unicode spelling survive. A present non-array or a non-dictionary element fails; present-invalid never becomes missing. No state value type is inferred from this transport container.

The original Rust `ShellControlStates` facet reads only that member, retaining original boxes without constructing cached hash keys. `write_to` installs or removes it in an owned envelope copy, preserving all other members. It can explicitly replace a malformed old member. `from_canvas_state` copies each HashablePlistBox's original value in order; its present-empty choice is an original adapter policy, not evidence that the native caller always chooses it. Native caller construction/projection remains a next step.

The `shell-control-states` inspector returns an original `{isPresent, controlStates?}` projection. Other envelope members are opaque; success does not validate a complete shell update. Summaries expose only presence/count. Raw canonical-key collisions remain explicit portable profile exclusions, and the existing binary-plist reader enforces depth/object/input limits. They are not claimed as native rejections.

## Actual runtime evidence

21 complete native shell decoding attempts: 13 success/encode compositions and eight malformed-control-state errors. The 13 accepted cases cover absence, present-empty, an empty box, duplicates, order reversal, unknown/nested fields, distinct Int/Real/Bool wire types, Date, Data and composed/decomposed Unicode. The native encoder drops an unknown envelope member while preserving unknown members inside a PlistValueBox. The portable inspector deliberately projects only the selected field and the library's envelope-edit operation preserves other fields; neither claims to reproduce the complete native envelope codec.

A real minimal native fixture was recovered: static previewType, pid zero, owned content identifier/category strings, empty contentPayload/staticProducts and an empty setup. Setup's dynamic product wire key is `products`, even though the stored field is named `dynamicProducts`. Initial exploration incorrectly used the stored field name as the wire key; all 27 exploratory envelopes failed. Those inputs/results are retained separately. Adding the source-recovered `products` key admits the valid fixture. This failure was a harness schema assumption, not an access/tool block or native lifecycle failure. Other product/setup/type/seed schemas are not implemented in Rust here.

Metadata checks qualify native ShellUpdatePayload kind512, size/stride/alignment176/176/8 and field offsets0,8,24,40,56,72,88,104,112,120,168. Exact loaded module paths/offsets, disk SHA/UUID and selected source bytes are verified before use. Foundation/Swift/Messaging runtime image UUIDs are compared on fresh replay. The original indirect-result bridge forwards x0/x1, x8/result and x20/self with x21/error isolation. Decoder takes ownership of the source PropertyList word on success/error; consumed source buffers are deallocated without double destruction. Successful encoded dictionaries are copied before direct native PropertyList and Shell destruction; failed output buffers are never read or destroyed. Eight captured Swift errors are explicitly released.

Direct returns:13 Shell destruction calls,13 encoded PropertyList destruction calls,8 error-release calls. Input/output fixtures may independently retain objects. These observations establish scoped value survival, not unique object ownership, final release, heap quiescence or global settlement. Native runs have8-second deadlines; owned libraries remain loaded through helper exit. No native crash/timeout/load/layout failure occurred in the final harness.
