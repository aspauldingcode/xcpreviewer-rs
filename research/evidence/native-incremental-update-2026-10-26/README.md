# Incremental-update single-entry wire subset

Original reconstruction and owned native value harness against pinned shipped PreviewsMessagingHost/PreviewsFoundationHost images. The source verifier checks 2,540 instruction bytes and protocol metadata. The native value has kind512, size/stride64, alignment8, field offsets0/16, destructor0x72978. Decoder0x72210 consumes PropertyList indirectly; encoder0x72154 receives indirect self. Payload is PropertyListType & Hashable, not an update registry.

The decoder reads the serializable dictionary, asks its hash table for the first occupied bucket and extracts that entry. It does not require exactly one key. Empty input produces the empty unarchive error; a first value that cannot dynamically cast to the protocol composition produces invalid. Actual fixtures accept String, Bool, signed/unsigned numbers, finite and nonfinite Real, and Data; reject Foundation-parsed Date, Array and Dictionary. Empty and Unicode/NUL keys survive. Sixteen independent copies of the same three-member dictionary select different sole members during one owned invocation. Their selection is intentionally not matched across replay processes. No assertion about every custom native conforming type is made.

Portable PreviewIncrementalUpdate::decode_single_entry and incremental-update-single CLI accept the deterministic single-entry subset. Multiple entries return AmbiguousNativeSelection, a portable restriction rather than native schema rejection. New validates scalar/data values. The original key/value is retained; no native equality/hash or application/dispatch is implemented. Summaries expose neither key nor payload. A private writer path preserves nonfinite Real bits for this codec; generic public writer rejection and limits remain unchanged. Date remains excluded. IEEE NaN payload preservation is original writer behavior; native fixture qualifies one serialized quiet NaN, not all NaN payloads or NSNumber internals.

One initial metadata guard incorrectly expected56 bytes and SIGTRAPed before any decoder call. The corrected64-byte layout was checked with a bounded metadata-only probe, field offsets and source copy methods. The initial guard helper/stderr are retained. One initial cross-runtime check failed on infinity because the existing generic writer rejects nonfinite values. A codec-only private writer path and explicit generic-contract regression tests address that failure. No user process was touched.

Qualification concerns serialized values parsed by Foundation. In the combined native output, Foundation may coalesce equal NSNumber Real objects: the positive-zero control is reported as negative zero in the retained fixture. It therefore does not independently qualify positive-versus-negative-zero object identity or serialization. No native registry, update execution, setup/full shell, transport, resource settlement or UI/provider behavior is claimed. Both milestones remain incomplete; UI/provider quarantine persists.

Run verify.py for a fresh disposable focused replay. Native calls and metadata probe use8-second deadlines; compiler steps30seconds; WASI10seconds. Raw Apple assembly is retained only in ignored local research/raw. Public files contain original code/helpers, owned fixtures and sanitized findings.
