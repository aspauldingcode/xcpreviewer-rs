# Crash-report prerequisites and remote request recovery

Direct GhidraVibe/ARM64 recovery of RemoteEventRequestPayload establishes two variants: requestScreenshot has no decoded payload; symbolicateCrashedDiagnostics requires a CrashReport. The request decoder is0xaef7c (476 bytes), serializer0xaebd8 (512 bytes), discriminant getter0xae8bc and key getter0xaeb8c. Swift long-string literals resolve to0xc76c0 and0xc76e0 after their pointer bias. These requests are not generic subscription messages; that investigation hypothesis is rejected.

The original ScreenshotRequest API now decodes typed/binary values and emits the source-recovered decoded-value tree. It accepts requestScreenshot without reading unrelated crashReport fields. It explicitly rejects the symbolication variant pending report validation, and rejects unknown discriminants. No screenshot is requested from a live target and no message is sent. The Value-tree serializer is not a binary serializer.

## Missing date primitive implemented

CrashReport recovery located the MessagingHost wire adapter at0x386e4 (2260 bytes), encoder field builder0x38fe4 (1828 bytes), ID decoder0x397dc and Termination decoder0x3aa6c. Report time is a Foundation Date property-list value. FoundationHost's Date conformance witnesses0x9ac30/0x9ac48 perform identity copy/move rather than changing the value to a number/string. The portable binary reader therefore adds a distinct Value::Date(f64), supported only by the exact date marker0x33. The value is Float64 seconds since the CoreFoundation reference epoch,2001-01-01T00:00:00Z. It remains distinct from Value::Real; existing strict real-only payload fields do not silently accept a date.

An original public CoreFoundation oracle parses an independently generated plist array, checks each value's CFDate type and reads its absolute-time bits. Six owned dates span1970, the2001 epoch, positive/negative fractional intervals,2038 and a2026 microsecond date. All48 value bytes match independent Python expectations. The Rust parser reproduces every bit. This is an actual public native plist/date boundary, not a private Xcode/CrashReport invocation. Nonfinite dates, Foundation coercions and universal malformed-input parity are not qualified.

Thirty-nine Rust tests pass (35 prior plus4 suites), covering native date bit values and strict-prefix rejection, screenshot-request fixture roundtrip, ignored unrelated fields and explicit unknown/unsupported variants. The old unsupported-marker test now uses unsupported0x30;0x33 is a supported date. Fresh replay independently reproduces both Python fixtures, rebuilds/runs the public native oracle and runs all tests without source mutation. Original fixtures, native values, logs and replay script are retained.

## Source frontier and limits

The report's source path includes an optional ID with a native new-UUID default, required name/bugType strings, Int32 PID, Date time, image/frame arrays and optional ASI, termination and logFilePath data. This is a source recovery frontier, not a validated complete report codec. ID parsing delegates to the Foundation UUID string adapter; do not substitute a fixed identifier for the native generated default. Nested image/frame/termination mappings, UUID behavior and bounded key-table recovery must be validated before admitting complete CrashReport support.

The report-key witness is only8 bytes and tail-branches to raw getter0x38468. Its decompiler result has spurious out-of-domain switch cases and broad control-flow expansion. That inference is quarantined as complete key-schema evidence; the bounded witness instructions and raw result remain local. Other Swift error-register/unreachable warnings require instruction checks, not copying pseudocode as C. Raw decompilation/disassembly is not published.

REA6.2.0 identity, aligned server, FoundationHost SHA and MessagingHost SHA were verified; GhidraVibe0.1.1/GhidraMCP5.14.2 performed focused analysis. The prior remote-crash evidence seal was fully reverified. Exclusive locking and bounded native subprocess/decompiler deadlines were used. The REA session and analysis lock were released. A failed cached-symbol query and corrected preverification expected-constant transcription are retained explicitly; neither is promoted to native evidence.
