# Native built artifact value codecs

This unit qualifies BuiltObjectFileDescription, BuiltStaticArchiveDescription and BuiltTargetDescription.PlatformVersion wire values. It does not open/replace/load/link files, parse versions, choose architectures, arbitrate product reuse, qualify complete built-target/static/setup/shell payloads, run real update transport or prove native UI/provider/final resource settlement. Both milestones remain incomplete.

Objects require path String; identifier is an optional String, including empty. Missing sourceFilePaths defaults to an empty String Set, missing forReplacement defaults true. Present malformed optional fields fail; Bool accepts serialized Bool and numeric exactly0/1. Output always emits path, emits identifier only when present, sourceFilePaths only when nonempty and forReplacement only when false. Archives require path with optional identifier; unknown fields drop. Platform version requires String name, minVersion and sdkVersion; empty/arbitrary strings are accepted without parsing. Original Unicode/NUL/supplementary Strings survive.

sourceFilePaths has native Set<String> semantics: duplicate/canonically equivalent Unicode paths collapse; tested first spelling survives. Owned fixtures cover both composed/decomposed insertion orders, repeated paths, empty/NUL/supplementary paths and mixed-type rejection. Native Set iteration/wire order is randomized and explicitly excluded from comparisons. Original Rust SourceFilePaths retains first spelling keyed by NFD and deterministically emits paths in ascending NFD-key order. This preserves membership and representative values; it does not reproduce native randomized order/hash bits. Other fields and arrays retain normal typed comparison. Whole product equality/hash is not qualified; derived Rust archive/platform equality is structural. Exact simultaneous-malformed-field error selection and custom NSNumber behavior remain outside scope.
