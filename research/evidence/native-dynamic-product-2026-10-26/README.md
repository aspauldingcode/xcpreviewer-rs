# Native dynamic product wire codec

This unit qualifies the value description of DynamicLoadablePreviewProduct on the pinned shipped frameworks. It does not open or execute a product, resolve a path, select a loader, set dlopen flags or establish real update transport, UI/provider completion or resource settlement. Static products, incremental updates, setup and full shell assembly remain open. Both milestones remain incomplete.

The seven wire fields are path, executablePath, location, loadingStrategy, moduleName, externalFunctionBinding and isRequired. The three String fields are required, including empty Strings. loadingStrategy requires bundle/direct/xojit; externalFunctionBinding requires default/immediate. Missing location defaults to absolute (other case embeddedFrameworks). Missing isRequired defaults true. Present malformed optional values fail. Bool accepts serialized Bool and numeric exactly0/1; other tested numeric values fail. Canonical output emits all seven fields, normalizes Bool, drops unknown members and preserves original String data, including Unicode/NUL/supplementary characters. Rust equality is structural wire equality; native String/product equality/hash is not qualified.
