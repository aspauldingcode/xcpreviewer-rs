# Selected reconstruction paths: repository ancestry audit

The159-file inventory establishes current source identities but not origin. This follow-up examines six selected delivery-boundary paths: the Rust contract, WASM template and library, the live WASM host, source revision host and preview MCP entrypoint. It uses two committed analysis documents as explicit repository-history anchors: initial findings and the unfulfilled-state deinit investigation. The audit captures only commit/tree metadata; it does not copy target or reconstruction source into a clean handoff.

All six paths have one recorded path-addition commit in the queried history. Both analysis-document addition commits are ancestors of each of the six candidate addition commits. Twelve `git merge-base --is-ancestor` observations are cross-checked through a separate `git rev-list --ancestry-path` query, with the full returned commit lists retained. This establishes repository ordering. It does not establish who read what, whether code was derived from an analysis document, whether it was independently authored, or whether any copying occurred.

Method limits matter: this queries additions under current pathnames and does not follow renames or recover conceptual authorship before files entered Git. Branch history, squashing, imported code, unrecorded conversations and uncommitted drafts can leave gaps. Commit timestamps are not used as a substitute for ancestry. The separate Git query is mechanical corroboration, not the fresh-context semantic/provenance review required by the clean-room graph.

Every selected path stays quarantined, origin unestablished and handoff eligibility false. Neither task nor milestone acceptance changes. The prior inventory seal is verified. Bounded producer queries cap candidate/anchor/addition counts, per-command time and total elapsed time. The independent reader rejects seven resealed false provenance/ancestry claims. Source tests contrast an actual temporary Git repository's ordered commits with the explicit refusal to grant clean-room status.
