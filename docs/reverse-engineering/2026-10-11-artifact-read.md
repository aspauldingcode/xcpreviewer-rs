# Bounded Rust artifact descriptor gate

The Rust source builder previously performed lstat on a module pathname and then readFileSync on that pathname. A replacement between those operations could change type or size, making the precheck insufficient to bound the actual read. Production now opens with O_RDONLY|O_NONBLOCK|O_NOFOLLOW, validates the opened descriptor as regular/nonempty and at most1MiB, reads at most limit+1 bytes, checks exact byte count and pre/post dev/ino/size/mtimeNs/ctimeNs, and closes in finally. The module digest must still match the compiler receipt. This protects the final pathname component; it is not an ancestor-symlink sandbox, arbitrary filesystem isolation or kernel resource reclamation claim.

Eight real owned filesystem cases test the reader: valid freshly compiled WASM, empty, oversized, directory, FIFO, symlink replacement immediately at open, growth after a read and same-size mutation with changed mtime. The FIFO has no writer and rejects through nonblocking open/regular-type validation. Deterministic call-boundary instrumentation mutates real owned files; it does not replace the production read helper. Descriptor counters track only production opens carrying the required nonblocking flags and their closes, excluding fixture-writing descriptors. Valid returns exact module bytes/hash; seven cases reject. Every opened production descriptor has a matching close call. Each worker is a fresh owned Node subprocess with a2s deadline and actual successful exit; no user process is targeted.

The independent reader verifies the complete seal and existing toolchain/source/allocation evidence, derives the valid module digest from its compiler receipt, checks the eight predefined outcomes and descriptor accounting, then reconstructs all eight filesystem cases and executes the frozen production helper in fresh processes. Three resealed mutants falsify FIFO acceptance, descriptor close count and valid bytes/hash; all reject.
