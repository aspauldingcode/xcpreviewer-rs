This probe changes the callback contract explicitly: the owned source writes an atomic readiness record containing PID/parent/group and independently queried dyld executable path, then remains alive. Only that controlled ready acknowledgement gates first live-root snapshots. The callback verifies the Popen target equals this owned running PID and parent equals the controller. This is an explicit probe protocol, not a generic delay or implicit readiness policy for real compilers.
