# Canvas pilot reports: sealed-evidence crosswalk

The50-statement review catalog was pinned to ten report documents, but literal report text alone does not bind its underlying experiment artifacts. This follow-up resolves report references to eleven distinct sealed evidence manifests and verifies their full declared file inventories. It supports separate-context evidence review; it does not perform that review or create semantic support edges.

The resolver recognizes inline evidence directories, Markdown paths and bare manifest hashes. The hash-only MCP quarantine report now resolves to its actual sealed experiment. All eleven referenced artifact sets pass current byte-size/digest and complete-file-set checks. Nine links also have their computed manifest digest literally mentioned in the pinned report. Two path-only references do not: native state binding and the preliminary partial-right control. Those remain explicitly unanchored by a report-mentioned digest; they are not silently upgraded to externally trusted or semantically accepted evidence.

No existing experiment or native process was rerun; padding/tail files are hashed as complete files rather than compared anew with pixel oracles.

Tests cover inline/hash/path linking, missing document anchors, changed payloads, extra unsealed files, symlinks, changed report identities and byte-budget rejection.
