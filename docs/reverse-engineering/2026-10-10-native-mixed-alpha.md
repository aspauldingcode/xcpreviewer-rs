# Mixed-color alpha export and failed rounding generalization

Two independent sealed campaigns execute an owned SwiftUI ImageRenderer fixture at17×9, scale1, Aqua, explicit nonlinear sRGB. Ten cases each run twice in fresh processes: four discovery cases, four predeclared holdouts, transparent and opaque endpoint controls. Every decoded straight RGBA byte and all repeat pairs compare without normalization. The fixture uses byte-grid channels converted through `Double(channel)/255`; this specifies inputs, not the internal precision of SwiftUI Color. No Xcode window opens.

All predictions are written before compilation and capture. Competing rational formulas predict direct straight channel export, half-up premultiplication using exact source alpha, and half-up premultiplication using already-quantized alpha. Export unpremultiplication uses the quantized alpha integer. Each model compares12,240 bytes per campaign; the same actual bytes are reused across models, not counted as independent observations. Matches per20 captures are6,18 and16 respectively, identically in both campaigns. Holdout matches per8 captures are2,8 and4. The endpoint controls and one nondiscriminating holdout agree across models; the other holdouts distinguish them.

For `(51,153,230)` at three-quarter alpha, native output is `(51,154,230,191)`, while exact-alpha half-up predicts blue231. This falsifies a tempting generalization of the earlier primary-red alpha controls. A subsequent independently declared ties-to-even premultiplication model predicts the original cases and four new half-tie holdouts. It matches20/28 captures, including all original20, but fails every new holdout pair. In particular `(5,9,13)` at half alpha produces `(4,10,12,128)` rather than the predicted `(4,8,12,128)`; `(7,11,15)` produces `(6,10,14,128)` rather than `(8,12,16,128)`. The other new holdouts use `(4,12,20)` at three-eighths and seven-eighths alpha and also contradict the model. The failed hypothesis remains sealed with an inconclusive controller verdict and explicit failure memory. It is never promoted into a portable implementation.

All68 captures,41,616 decoded RGBA bytes and34 same-input pairs repeat exactly. These observations support deterministic output and formula discrimination; they do not identify an internal rounding implementation. Color representation precision, intermediate buffers and TIFF/PNG export remain competing explanations. All recorded PNGs are RGBA17×9 with no ICC profile. Compressed PNG bytes, native raw stride/padding and general profiles/gamuts are outside the claimed comparison. Existing portable red/blue and alpha subsets remain unchanged.
