# Public renderer callback and a persistent pixel counterexample

The public ImageRenderer drawing callback now draws the same14 owned mixed-alpha SwiftUI views into initialized CGContext targets. Signature/actor requirements were checked against the installed public SwiftUICore interface and compilation. Inputs retain17×9 geometry, scale1, Aqua and nonlinear sRGB. Every target must receive exactly one callback reporting17×9. Active pixels start transparent zero; row padding starts0xa5.

The first campaign compares normal/copy blend states in explicit big-endian premultiplied RGBA stride80 targets. Both targets repeat and have equal complete buffers, but each matches the independently anchored cgImage provider in only26/28 executions. Case12, `(4,12,20)` at three-eighths alpha, draws premultiplied `(1,4,7,96)` through the callback while cgImage supplies `(1,4,8,96)`. Blue differs in every one of153 pixels of both fresh processes. Opaque controls pass; this is not a successful complete substitute for cgImage.

A2×2 matrix then varies stride68/80 and default/explicit-big RGBA bitmap flags. All four targets remain26/28 against the native provider; case12 remains the same counterexample. Distinct opaque source controls prove the admitted RGBA mapping. Every reported layout/request identity, geometry and callback count is checked. Matrix targets preserve all padding.

The final matrix report explicitly separates complete allocations from active pixels. Full buffers with different strides have different lengths and padding, so they are not equal representations. Exact physical pixel extraction copies only the declared68 active bytes per row, without changing values, order, alpha or color. All84 non-self target-to-baseline active comparisons pass,51,408 reused pixel bytes. Padding is independently included in full allocation/model/native-derived comparisons. The initial matrix seal is retained; its generic `all_blend_equal` field compared differently sized allocations and must not be interpreted as a pixel or blend-mode difference. Corrected report naming and target-specific prediction metadata remove that ambiguity.
