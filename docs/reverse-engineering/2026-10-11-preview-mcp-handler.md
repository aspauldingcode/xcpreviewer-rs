# Owned preview MCP message handler (2026-10-11)

The custom stdin transport rejects a real MCP initialize envelope with zero accepted requests and zero replies. It cannot be advertised as MCP. A separate PreviewMcp handler now implements a bounded message-level subset: version negotiation, initialized notification, ping, tool discovery and five owned preview session calls. Tool operation failures use isError content; malformed/unknown method/argument errors use JSON-RPC errors. Request IDs retain string/integer type, including zero and empty string, and cannot be reused. Opaque reserved parameter metadata is accepted for supported tools. Only the tools capability is advertised.

Predictions: custom NDJSON rejects initialization; the new handler negotiates2025-11-25 even for a different client version, waits for initialized before tools, suppresses notification replies, retains synthetic frame after operation failure and hides the thrown private message. Independent Python checks confirm those predictions and two fresh Node replays. Two synthetic16KiB allocations compare every byte against an independent arithmetic expectation. Nine malformed messages and the256-request ID bound are checked. Three resealed wrong-version, leaked-error and corrupted-allocation claims reject.

The owned fake session isolates message semantics. This is not a functioning MCP stdio server, an SDK interoperability result, actual compilation or native Canvas evidence. The caller must await handle serially, own UTF-8 framing/parse errors, enforce deadlines/backpressure, route cancellation and close the session on EOF. Batch, transport concurrency/cancellation, client disconnect negotiation and real compiler integration remain untested. Input serialization is capped4096 bytes, string IDs128 bytes, output32768 bytes. The handler's limits are application bounds, not MCP universal requirements. A finite request limit keeps ID memory bounded; the future transport must document/reconnect at exhaustion. No resources/prompts/logging/tasks capabilities are advertised.
