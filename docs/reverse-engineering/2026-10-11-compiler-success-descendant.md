# Successful compiler root does not prove descendant quiescence

The previously measured timeout group cleanup does not establish normal-success descendant cleanup. This owned source-level experiment calls the actual sourcecache.run_compiler boundary with a Python root that forks one finite same-group child. Root waits for the child's first controlled byte, reports its PID/group/child identity and exits 0. Child appends exactly bytes 0 through 23 at 50 ms intervals, then writes its completion record and self-exits. No user process is read or killed; only generated files are changed. This is fully available owned source execution, not a shipped Apple runtime claim requiring binary REA analysis.

The qualified invocation returns root code 0 in approximately 0.156 seconds, while heartbeat has only byte 0. At the separate 300 ms observation it contains bytes 0 through 6; at finite completion it contains all 24 bytes. Actual root/child group identities agree with start_new_session and the controlled fork relationship. Therefore successful root return is not proof that its descendants have stopped writing. This falsifies that scoped quiescence interpretation; it does not demonstrate a corrupted published artifact or arbitrary compiler escape.
