# Independent WASM interpreter controls

The hand-authored opaque red/blue C renderer now executes in installed WasmKit 0.1.6, a Swift WASM interpreter, independently of Node/V8. Both execute on the same macOS host. This advances runtime feasibility; it does not establish source compatibility or a non-Apple platform.

The existing controller verifies the separately trusted native ImageRenderer oracle before decoding its red/red/blue frames. Original module execution in V8 still writes and compares all 614,400 native RGBA bytes and the independent 32-byte padded case. A separately compiled checker translation unit embeds native red/blue arrays and independent padding expectations, calls the original unchanged renderer, and compares every output byte. No LTO is used: the renderer is opaque to the checker compiler. The checker module has zero imports and fixed 1 MiB memory.

WasmKit's CLI exposes function results rather than an output-memory dump. Its result is therefore an internal mismatch count, not exported pixel data. The same checker module also executes in V8. Each engine reports zero mismatches across four cases (614,432 bytes). Eight intentional first/final-byte faults each yield exactly one mismatch, including the final padding byte of the 3×2 case. Ten invalid renderer requests return zero and preserve all 204,800 buffer bytes per request (2,048,000 bytes per engine). Three out-of-contract checker requests return the explicit unsigned sentinel. Missing, ambiguous, wrong-type and out-of-range CLI results fail parsing; nonzero subprocess exits fail execution.

An initial unsealed exploratory invocation supplied untyped integer CLI arguments and exited 133 with `unknown type`. That observation is retained separately and cannot certify acceptance. Changed `i32:value` arguments work. The first sealed positive campaign passes; the dependent rejection campaign passes; the final stricter-parser campaign passes. All three seals verify, including frozen sources. The full suite passes 117 tests.

Finite scope remains width 1–320, height 1–160, stride width×4 through 1280, opaque red/blue. Native arrays establish decoded RGBA equality; padding is synthetic. No PNG encoding equality, Swift frontend/runtime, SwiftUI compatibility, Canvas IPC, browser/non-Apple execution, text/fonts/layout/assets/state, hot reload or performance is established. These remain holdouts, and both milestones remain open.
