# Bounded owned preview channel

servePreview(input,output,session,options) is an owned NDJSON stream adapter over PreviewSession, not JSON-RPC or MCP. Requests are exact id/method objects; IDs must be positive safe integers and strictly increase. Methods are start, poll, status, frame and close. Responses identify id/ok and result or a generic error code. frame carries a descriptor and base64 full allocation. No arbitrary file paths, toolchain settings or builder execution commands enter through this wire. The caller configures its owned session separately.

Input is limited to4096 bytes through the next newline; invalid UTF-8, malformed/extra request fields and same-chunk pipelining close the channel. One operation executes and at most one parsed request queues. Queue overflow closes and drains; close has priority and discards pending requests before their response write. Responses are limited to32768 bytes. A write that backpressures waits for drain/error for a separately bounded50..1000ms deadline and removes those listeners/timer. A500..10000ms lifetime timer initiates stop; it is not a hard wall-clock guarantee for drain completion. The trusted PreviewSession and configured builder must honor bounded abort/close settlement; arbitrary injected sessions that never settle are outside this contract. An outer process deadline remains necessary. Stop clears input accumulation and lifetime timer, destroys the owned input, closes/drains the session, awaits the active dispatch, then ends output or destroys it on output failure. Counters distinguish accepted valid request shapes, rejected requests/operations, response-write attempts and operations suppressed before response write; they are not native process signal counts.
