# Count-bounded retained build metadata

`RustSourceBuilder` kept every successful receipt/execution record and every failure in unbounded arrays. Added a validated `historyLimit` option, default64 and range1–256. Each array now retains its newest entries, and `build.history()` reports the limit plus separate dropped-record/dropped-failure counts. Counters saturate at the safe integer maximum. Existing record/failure getters still return copies. Complete failure files and stage artifacts remain on disk; this change does not silently delete failure evidence.

Evidence: `research/evidence/bounded-build-history-2026-10-11`. A280request actual builder JS/staging workload substitutes a clearly synthetic execution boundary with alternating success/failure outcomes. Success receipts and module/generated bytes are copied from the pinned prior owned Rust fixture and pass the existing receipt validator. No compiler job runs. Before/after default cases each exercise130requests, exceeding64 records and64 failures; the configured case exercises10requests against a limit4. The fixed getter returns newest64/4 with one drop in each category. All140 failure artifacts remain copied into the sealed evidence, including failures removed from retained metadata. Invalid limits reject before root-directory creation.

The control retains raw owned stages locally at the path recorded in environment metadata. Twelve resealed faults reject wrong counts/order, lost failure artifacts, invalid configuration and overstated scope. One existing Node v24.19.0 control process has a12second deadline. No frame rendering, native compilation, private UI capture or actual native process retirement is inferred from the synthetic execution receipt.

This bounds retained entry counts only. Individual external diagnostic/record size, raw stage disk quotas, total lifetime work and cleanup policies remain independent hardening acceptance work. Both milestones remain open. The historical pre-abort evidence and source remain immutable, with its test now pinning its previous builder hash.
