# Exact-span review catalog for the Canvas evidence pilot

The graph's ten-document pilot now has50 statement candidates prepared for separate-context review. Five exact source spans per document are retained with source-node identity, document SHA-256, character and line ranges, literal quote, declared evidence grade, scope and target-version field. The current historical target-version fields remain unresolved wherever the source graph says so; the extractor does not guess versions.

This is candidate preparation, not fifty independently verified claims. Every row says document-statement-only, semantic review pending and acceptance qualification false. The semantic precision field is null, independently reviewed count is0, the50-item/>=90% quality gate is false, and no knowledge fusion or semantic support edges have been created. Exact textual grounding establishes what a report says; it cannot establish that the underlying experiment or inference is correct.

`tools/re/canvas_claim_catalog.py` deterministically extracts a bounded selection of prose statements from pinned source documents. Headings, tables and fenced blocks are excluded. This is a convenience sampler, not a complete parser or comprehensive research index. Exact lexical duplicates within the declared scope/version are suppressed; no semantic equivalence is inferred. Selection order is document order, so the sample is not a random or representative precision estimate.

Verification checks all50 literal character spans against current pinned source hashes, matching line ranges and node/grade/scope/version identities, uniqueness and per-document counts. Eight negative controls reject changed quotes/spans/line ranges/identities, false acceptance/precision/review and evidence-grade promotion. Separate source-identity and sampling-limit tests fail closed. The saved catalog and producer are sealed and compared with the planned coverage-audit output. No target binaries, native processes, product edits, agent delegation or clean implementation export were involved.
