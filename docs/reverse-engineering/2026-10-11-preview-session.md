# Local preview session consumer contract

PreviewSession is a local JavaScript module API over SourceFileLoop. It exposes start(interval,duration), poll(), status(), readFrame() and close(). status() has schemaVersion1, explicit finite primary scope, lifecycle counters, bounded diagnostics and a frame descriptor. readFrame() verifies the active WASM allocation and returns a detached Buffer plus detached descriptor. Empty or fully closed sessions return null. One async start/poll/read operation owns the API at a time; competing operations reject. close() remains available to abort/drain an in-flight operation. SourceFileLoop’s existing interval/duration limits and builder deadline still apply. No network or MCP server is introduced.

The host previously stored source/frame provenance without geometry. It now commits validated width, height and stride in the same active instance object as allocation/revision. Snapshots copy geometry. The consumer descriptor identifies revision, source generation/hash, module hash, allocation hash/length, rendered extent, width/height/stride and the declared premultiplied RGBA8 finite primary format. This format requires the configured finite primary builder and independent oracle; the module ABI alone is not general format attestation. Callers receive the full16384-byte allocation, including row padding and unused tail, and must honor descriptor geometry. Public status does not carry raw compiler records, stderr or toolchain inventories. Error strings remain bounded diagnostics, not path redaction. Private execution records stay with the configured builder.
